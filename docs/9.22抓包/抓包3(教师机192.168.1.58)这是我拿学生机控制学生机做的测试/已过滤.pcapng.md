### 3.4 双挂载（关键安全事实）
`.57` 在被 `.58` 全程接管期间：
- 继续向真教师 `.200` 发 10118 空连接探活（255 帧 / 324 s）；
- 继续接收真教师机 7771/7777 广播（本文件含 4 台 `.x.200` 的广播/心跳）；
- 同期真教师 `.0.200/.2.200` 的 7778 屏幕广播（229.1.0.200/229.1.2.200，93+13 MB）也在播。
→ **学生端对"教师"无排他/抢占逻辑，多教师并存**〔铁证〕。

## 五、结论
1. **协议层零鉴权**：9002 注册（`/ip/mac/ip/`）、9003 会话、9100 文件、9997 视频、8041 鼠标、8555 传输口、7777/7771/7778 广播——**全部可被同网段任意机器以同一软件复用**。`.58` 用学生端软件即可完成"教师"全部功能（本批实测黑屏×3、远程命令×6、文件下发 91MB、鼠标控制、屏幕视频拉取、全机房组播推送）。
2. **组播组号按 IP 推导**，学生机自发组播 `229.1.1.58`/`229.9.1.58` 与真教师频道不冲突 → 同网段多"教师"可并行存在。
3. **被控机双挂载无感知**：`.57` 不排他、不告警，对真教师 `.200` 的心跳照常。
4. 远程桌面链 = 9997（H.264 视频）+ 8041（鼠标）+ 8908（看门狗 `coming`）+ 9003 0x2B（JPEG 快照）——9.20 之前未观测到的**新远程交互协议簇**。

## 六、未决（本文件相关）
1. `.58` 侧"教师模式"入口（同一学生端切换 or 独立程序）——需 `.58` 本机证据；
2. 6 条远程命令（cmd 13）的具体正文未逐条解码（本文件仅解码回执 `"1"`；下发帧在 TCP 重组段中，需按流重组后解码）；
3. 9100 文件头完整字段语义（`b8 00 00 00`/`a8 00 00 00` 两 u32 待定）；
4. 8041 的完整 JSON 字段（`vend…` 截断，需取完整帧）与 message 值全集；
5. 8908 `coming` 的超时语义（停止后 .57 会怎样）。
