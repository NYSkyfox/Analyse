# 02 行为管控指令

> 本文汇总 Os-Easy 教学系统"行为管控"功能的完整分析：指令通道、报文格式、位标志、执行链路、安全结论。
> 数据来源：样本静态分析（逐指令反汇编）+ `skin/core.conf` + **2026-09-20 机房抓包**。
> 分析日期：2026-09-15 · 通道纠错：2026-09-20

> 行为管控为独立功能，与"远程命令"（[04 号](./04_远程命令执行.md)）、"黑屏肃静"（[17 号](./17_黑屏肃静功能.md)）分属不同指令。

## 一、管控指令通道

| 项 | 值 |
|---|---|
| 端口 | **`tcp/9003`**（`ConnectPort`，登录/心跳会话） |
| 协议 | TCP（长连接） |
| 载荷 | 40 字节二进制头 + JSON 子记录（详见 §二） |
| 方向 | 教师端 → 学生端 |

> **09-20 抓包实测**：8040/8045 UDP 全程 0 帧，管控指令走 `tcp/9003`。
> 配置项 `UdpMessageControllerPort=8040` / JSON `controller_port=8040` 仅为**声明值**，运行时不承载管控下发。
> 与"远程命令（cmdType=0x0D）""黑屏肃静（cmdType=0x0C）"同走 9003。

```
教师端 Teacher.exe
  └─ FUN_0059ca10  按位算 CtrlCode → 组装 JSON 子记录
       └─ FUN_005c7e10 → FUN_005cbcf0  经已建立的 9003 连接发送
══════════════════════════════════════════
学生端 MainLogic.dll（9003 接收）
  └─ FUN_100773f0  解析登录/管控子记录
       └─ 翻译成 JSON → UDP → 127.0.0.1:8045 → DeviceControl.exe
            └─ NetLimitInterface.dll → OeNetlimit.dll → 驱动执行
```

> 注：`127.0.0.1:8045` 是学生端**本地 IPC**（StudentLogic → DeviceControl），非外网通道。

## 二、线格式

### 2.1 子记录帧结构（09-20 抓包实测字节偏移）

9003 登录/初始化包内**串行打包多条子记录**，每条：

```
偏移  长度  内容
0x00  6     魔数 23 2b cd 2c 40 2c
0x06  2     0x40 0x2c（常量）
0x08  ...   序号 / 校验 / 类型 / 长度（中间字段语义〔推断〕，未逐字段坐实）
0x24  4     JSON 载荷长度（u32 LE）
0x28  ...   JSON 载荷（编码混用：UTF-8 与 UTF-16LE）
```

> 40 字节头中，**魔数**与**偏移 0x24 的 JSON 长度**可实测确认；中间字段语义待运行态进一步定位。
> 同一 TCP 段可串多条子记录（实测 848 字节包内串 4 条）。

### 2.2 与 20 字节定长头并存

9003 上有**两套帧**：
- **20 字节定长头**：心跳 `0x59` / 屏幕上报 `0x2B` / 远程命令 `0x0D` / 黑屏肃静 `0x0C`（见 [16 号](./16_9003通道报文结构.md) §三）；
- **40 字节子记录头**：登录配置 / 行为管控 / 学生标识 / 文件限制（本文）。

## 四、CtrlCode 位标志

反编译 `Teacher.exe FUN_005648c0`（位定义）：

| 位 | 值 | 管控项 | 字段 |
|---|---|---|---|
| bit0 | 0x01 | 网络禁用 | `DisabledNet` |
| bit1 | 0x02 | 键盘过滤 | `EnableNetKeyFilter` |
| bit4 | 0x10 | 应用禁用 | `DisabledApp` |
| bit8 | 0x100 | USB 禁用(变体1) | `DisabledUsb` |
| bit12 | 0x1000 | USB 禁用(变体2) | `DisabledUsb` |
| bit16 | 0x10000 | USB 禁用(变体3) | `DisabledUsb` |

### 4.1 取值规则（09-20 抓包 + 代码实锤）

CtrlCode **必带 `0xBC` 高位前缀**，实际值 = `0xBC000000 | 限制位`：

| 值 | 十六进制 | 含义 |
|---|---|---|
| **实际下发**（网络+应用+USB×3） | `0xBC011111` | 高标志 `0xBC000000` + `0x00011111` |
| **停止/清除全部** | `0xBC000000` | 只留高标志，限制位全清 |

> `0xBC` 高位为**必备标志**（实际值与停止值共有）。学生端按位置解析，缺高位（如裸 `0x01`）会被丢弃。
> 停止值 `0xBC000000`（=`-0x44000000`）由 `MainLogic.dll FUN_10077970`（`UnLoad`）退出时回发，代码实锤。

## 五、完整执行链路

```
教师端
  Teacher.exe FUN_005648c0  读 NPDControl.json → 按位算 CtrlCode（加 0xBC 高位）
    └─ FUN_0059ca10  组装子记录 {CtrlCode, sendState, tipInfo, serverIp}
         └─ FUN_005c7e10 → FUN_005cbcf0  经已建立 9003 连接发送（不硬编码端口）
════════════════════════════════════════════════════════════
学生端（9003 接收）
  MainLogic.dll FUN_100773f0  解析登录/管控子记录
    └─ 翻译成 {"type":"support-use-device-control"/"stop-device-control",...}
         └─ UDP → 127.0.0.1:8045（本地 IPC）
              └─ DeviceControl.exe
                   ├─ NetLimitInterface.dll → OeNetlimit.dll → OeNetLimit.sys (WFP 断网)
                   ├─ \\.\ProcFireWall (禁应用)
                   └─ easyusbctrl.dll → easyusbflt.sys (禁USB)
```

> 学生端 StudentLogic.dll / Student.exe **不含 `CtrlCode` 字符串** → 按位置/偏移解析子记录，非按 key 名匹配。
> 网络位执行落在 **OeNetLimit 驱动**（白名单+默认拒绝，见 [OeNetLimit_sys](../components/OeNetLimit/OeNetLimit_sys.md)）。

## 六、驱动级限制原理

| 驱动 | 机制 | 能力 |
|---|---|---|
| `easyusbflt.sys` | 设备栈过滤 + USB 白名单 | USB 限制 |
| `KbFilter.sys` | Hook IRP_MJ_CREATE + IOCTL | 键盘锁（多级） |
| `OeNetLimit.sys` | NDIS LWF + WFP + 速度控制 + DNS 白名单 | 网络限制/断网/限速 |
| `ProcFireWall.sys` | PsSetCreateProcessNotifyRoutine | 程序限制 |
| `FbdATS.sys` | SFilter 文件过滤 | 文件监控 |

### KbFilter.sys 键盘锁等级（IOCTL）

```
IOCTL_KB_INIT / IOCTL_KB_STOP / IOCTL_KB_DISABLE_SPEC
KEYBOARD_ALL_DISALE                              // 全锁
KEYBOARD_ALL_DISALE_EXCEPT_CTRLENTER             // 除 Ctrl+Enter
KEYBOARD_ALL_DISALE_EXCEPT_PASSWORD              // 除密码
KEYBOARD_ALL_DISALE_EXCEPT_PASSWORD_AND_CHINESE  // 除密码+中文
KEYBOARD_ALL_DISALE_EXCEPT_PASSWORD_AND_CHINESE_AND_ALT
KEYBOARD_DISABLE_TASK_MGR                        // 禁任务管理器
KEYBOARD_ALL_RELEASE                             // 释放
```

### OeNetLimit.sys 网络限制

```
IOCTL_SET_SpeedControl disableInternet:%d disableNet:%d isDownLimit:%d
WfpRegisterCallouts / FwpmFilterAdd   // WFP 过滤
AddDnsWhiteListIp                      // DNS 白名单
ProcessCreateMon                       // 进程创建监控
```

## 八、安全结论

管控走 **9003 TCP 连接绑定**，非 8040 UDP：

- 学生端**不监听 9003**（是学生用临时端口**主动连入**教师 9003），第三方无法直接注入管控子记录；
- 唯一注入途径 = **IP 伪装 + 连接劫持（MITM）** 既有 9003 会话；
- `core.conf` `/IpAddressFilter//` 为空，但 9003 靠连接绑定的会话身份天然防护。

> 详见 [23 号](./23_20260920_管控通道纠错实证.md) §六 证据强度。

## 九、工具开发报文

> ⚠ 管控走 9003 **TCP 会话**，**不能**像 UDP 那样直接 `sendto`。
> 需先复刻"学生端连教师 9003 → 登录握手 → 下发子记录"完整会话，
> 且 CtrlCode **必带 `0xBC` 高位**。

子记录组包（核心 40B 头 + JSON）：

```python
import struct, json

def build_subrecord(payload_obj, is_utf16=False):
    if is_utf16:
        payload = payload_obj if isinstance(payload_obj, bytes) else json.dumps(payload_obj).encode('utf-16-le')
    else:
        payload = payload_obj if isinstance(payload_obj, bytes) else json.dumps(payload_obj).encode('utf-8')
    # 头 40 字节：魔数 6B + 常量 2B + 中间字段(占位) + jsonlen@0x24 + ...
    # 中间字段(0x08~0x24)需按目标学生端解析要求填充，待运行态坐实
    hdr = bytes([0x23,0x2b,0xcd,0x2c,0x40,0x2c])      # 魔数
    hdr += bytes(0x1C)                                  # 中间字段占位(序号/校验/类型/长度)
    hdr += struct.pack('<I', len(payload))              # 偏移 0x24: JSON 长度
    return hdr + payload

# 禁用网络(需带 0xBC 高位)
build_subrecord({"CtrlCode": 0xBC000001, "sendState":1,
                 "serverIp":"192.168.1.200",
                 "tipInfo":"网页已经被拦截，请不要搜索限制内容!"})
# 停止全部
build_subrecord({"CtrlCode": 0xBC000000})
```

> 上式仅给出子记录**字节格式**；**完整可发送**需在已建立的 9003 会话上发送，
> 中间头字段（序号/校验）需匹配学生端解析，见 [23 号](./23_20260920_管控通道纠错实证.md) §七 未决项。
