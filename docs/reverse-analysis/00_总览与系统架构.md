# Os-Easy 多播教学系统 — 逆向分析报告（总览）

> 目标样本：`/analyze/Os-Easy/os-easy multicast teaching system`
> 版本：V10.9.1.5145　|　架构：x86 PE（32位）|　分析工具：Ghidra 12.1.3 + objdump + strings
> 分析日期：2026-09

## 一、技术栈

| 类别 | 技术 |
|---|---|
| UI 框架 | MFC / Win32 GUI、DuiLib（皮肤）、Qt5（toolkits 辅助工具） |
| 网络 | Boost.Beast（WebSocket 2.90）、Boost.Asio、libcurl、WS2_32 |
| JSON | jsoncpp（`Json::Value`） |
| 音视频 | FFmpeg（avcodec-57/avformat-57/x264）、SDL2、VLC |
| 加密 | CryptoPP、Windows BCrypt、OpenSSL（libssl/libcrypto） |
| 第三方管控 | **LISS SDK**（行为管控核心） |
| 编译环境 | VS2015（MSVC140），编译路径 `D:\dmt\master\...` 泄露 |

## 二、核心组件

| 角色 | 程序/库 | 职责 |
|---|---|---|
| 教师端 | `Teacher.exe` + `MainLogic.dll` | 控制端主程序 + 核心逻辑（频道注册、端口配置、指令分发） |
| 学生端 | `Student.exe` + `StudentLogic.dll` | 接收端 + 学生逻辑（WebSocket 接收、指令执行） |
| 守护进程 | `MMPC.exe`（Windows 服务） | 行为管控执行者、进程保护、键盘锁 |
| 多客户端 | `MultiClient.exe` | 中继/多客户端管理 |
| 设备管控 | `DeviceControl_x64/x86.exe` | 设备/网络/应用/键盘管控执行 |
| 屏幕广播 | `ScreenSender.exe` / `ScreenRender.exe` | 屏幕编码发送 / 解码渲染 |
| 基础库 | `MmcImplBase.dll` | OE_* 基础函数（关机、杀进程、网络、锁） |
| 系统操作 | `systemoper.dll` | SYS_* 导出（关机、运行命令、锁屏） |

## 三、驱动清单（行为管控底层）

| 驱动 | 类型 | 管控能力 |
|---|---|---|
| `easyusbflt.sys` | 设备栈过滤 | USB 白名单（idVendor/idProduct） |
| `KbFilter.sys` | 键盘过滤 | 键盘锁（多级 IOCTL） |
| `OeNetLimit.sys` | NDIS LWF + WFP | 网络限制/断网/限速/DNS白名单 |
| `ProcFireWall.sys` | 进程通知 | 程序限制 |
| `FbdATS.sys` | SFilter 文件过滤 | 文件系统监控 |

所有驱动均有 `OEDRV_IsPassProcess`，用于豁免白名单进程自身。

## 四、身份判定

`MMPC.exe` 初始化时读取 `TeaSide.ini` 的 `[TeaSide]` 节 `Flag` 值：
- `Flag=1` → `Teacher Side.`（教师端）
- `Flag=0` → `Student Side.`（学生端）
