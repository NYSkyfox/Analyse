# 05 远程关机 / 重启

## 一、执行核心：OE_SystemOff（MmcImplBase.dll 导出）

反编译 `MmcImplBase.dll FUN_10006580`（OE_SystemOff），完整还原关机/重启逻辑：

```c
uFlags = 0;
GetVersion();
if (Win2000) {
    param_1==1 → uFlags=9   // EWX_POWEROFF | EWX_FORCE
    param_1==2 → uFlags=2   // EWX_REBOOT
} else {
    param_1==1 → uFlags=0xC // EWX_POWEROFF | EWX_FORCE
    param_1==2 → uFlags=6   // EWX_REBOOT | EWX_FORCE
    param_1==3 → uFlags=4   // EWX_FORCE
}
// 1. 提权 SeShutdownPrivilege
OpenProcessToken → LookupPrivilegeValueW("SeShutdownPrivilege") → AdjustTokenPrivileges

// 2. 主路径：ExitWindowsEx
ExitWindowsEx(uFlags, 0);
if (成功) return 1;
Sleep(3000);
ExitWindowsEx(uFlags, 0);      // 重试
if (失败) {
    Sleep(1000);
    ExitWindowsEx(uFlags|4, 0);  // 切换 EWX_FORCE 再试
    ...
    // 3. 兜底路径：shutdown.exe 命令
    if (param_1==1) _system("shutdown.exe -f -s -t 0");  // 关机
    else if (param_1==2) _system("shutdown.exe -f -r -t 0"); // 重启
}
```

### 参数含义

| param_1 | 操作 | uFlags（非 Win2000） |
|---|---|---|
| 1 | 关机 power off | 0xC = EWX_POWEROFF\|EWX_FORCE |
| 2 | 重启 reboot | 0x6 = EWX_REBOOT\|EWX_FORCE |
| 3 | 强制 | 0x4 = EWX_FORCE |
| 4 | 锁屏 | LockWorkStation() |

## 二、systemoper.dll 的 SYS_Shutdown（另一套实现）

反编译 `systemoper.dll FUN_10006fb0`，逻辑类似：

```c
case 1: 关机 → ExitWindowsEx(0xC, 0)   // EWX_POWEROFF
case 2: 重启 → ExitWindowsEx(0x6, 0)   // EWX_REBOOT
case 3: 注销 → ExitWindowsEx(0x0, 0)   // EWX_LOGOFF
case 4: 锁屏 → LockWorkStation()
// 提权 SeShutdownPrivilege 后 ExitWindowsEx
```

导出函数：`SYS_Shutdown`、`SYS_LockScreen`、`SYS_RunCommand`、`SYS_RunProcess` 等。

## 三、⚠️ 映像劫持问题解答（你观察到的现象）

你观察到的：**映像劫持 shutdown.exe 能阻止远程关机，但阻止不了远程重启**。

原因分析（结合 `OE_SystemOff` 代码）：

1. **主路径是 `ExitWindowsEx` API**，关机和重启都先走这条路径；
2. **兜底路径才是 `shutdown.exe` 命令**（仅当 ExitWindowsEx 多次失败后）：
   - 关机兜底：`shutdown.exe -f -s -t 0`
   - 重启兜底：`shutdown.exe -f -r -t 0`
3. **关键差异在 Windows 系统行为**：
   - `ExitWindowsEx(EWX_POWEROFF)`（关机）在较新 Windows 上，系统**会启动 `shutdown.exe` 进程来完成关机流程**，因此劫持 `shutdown.exe` 会导致关机链路断裂；
   - `ExitWindowsEx(EWX_REBOOT)`（重启）由 **winlogon.exe / 内核直接处理**，不经过 `shutdown.exe`，因此劫持 `shutdown.exe` 无效。

> 结论：**关机路径依赖 `shutdown.exe`（可被映像劫持阻止），重启路径不依赖 `shutdown.exe`（无法被映像劫持阻止）**，这与你的观察完全吻合。

## 五、完整链路

```
教师端 Teacher.exe
  └─ 远程关机/重启按钮（poweroff / shutdown 指令）
       └─ 通过管控通道（WebSocket/UDP）发送到学生端
            └─ 学生端 StudentLogic.dll / Student.exe 接收
                 └─ 调用 MmcImplBase.dll OE_SystemOff / systemoper.dll SYS_Shutdown
                      ├─ ExitWindowsEx(EWX_POWEROFF/EWX_REBOOT)  [主路径]
                      └─ shutdown.exe -f -s/-r -t 0              [兜底，可被劫持]
```
