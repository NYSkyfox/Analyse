# 04 远程命令执行（逆向 + 抓包实证）

> 本文汇总"远程命令执行"功能的**静态逆向**与**现场抓包**两方面的分析结果。
> 数据来源：样本静态分析 + 2026-09-15 现场 Wireshark 抓包。
> 分析日期：2026-09-15

---

## 一、功能定位

教师端"远程命令"功能：教师端下发命令 → 学生端执行。

| 项 | 值 |
|---|---|
| 通道 | `tcp/9003`（`ConnectPort`） |
| cmdType | `13`（`0x0D`） |
| 方向 | 教师端 → 学生端（回执反向） |
| 正文编码 | UTF-16LE |
| 正文格式 | JSON |

> 远程命令为独立功能，与"黑屏肃静"（[17 号](./17_黑屏肃静功能.md)）分属不同 cmdType。

---

## 二、报文格式（现场抓包实证）

### 2.1 教师端下发

`123456.json`，线上实际 194 字节（total_len 字段 = 190）：

```
HDR  : BE 00 00 00 | 0D 00 00 00 | 00 00 00 00 | 00 00 00 00 | 00 00 00 00
       (190)        (13)                                   (body_len=0)
BODY : (UTF-16LE, 多行, 174 字节)
{
   "Para" : "echo 123",
   "Path" : "C:\\Windows\\System32\\cmd.exe",
   "Tag" : 0
}
```

> ★ 正文为**多行 JSON**（换行 + 3 空格缩进 + 尾部换行），路径反斜杠**双写** `\\`。
> `total_len` 字段 = `16 + 174 = 190`（`0xBE`），线上实际字节 = 20(头) + 174 = 194。

### 2.2 学生端回执

线上实际 22 字节（total_len 字段 = 18）：

```
HDR  : 12 00 00 00 | 0D 00 00 00 | 00 00 00 00 | 00 00 00 00 | 02 00 00 00
       (18)         (13)                                  (body_len=2)
BODY : "1"  (UTF-16LE)
```

### 2.3 正文 JSON 结构

```json
{
  "Para": "<命令行参数>",
  "Path": "<可执行文件完整路径>",
  "Tag": 0
}
```

| 字段 | 说明 |
|---|---|
| `Path` | 被执行的程序（实测 `C:\Windows\System32\cmd.exe`） |
| `Para` | 传给程序的参数（实测 `echo 123` / `echo hhhh`） |
| `Tag` | 标签，实测恒为 0 |

### 2.4 实测样本

| 时间 | 文件 | `Para` | 长度 | 回执 |
|---|---|---|---|---|
| 09:46:xx | `456.json` | `echo 123` | 194 | 2 条 `"1"` |
| 09:48:xx | `123456.json` | `echo 123` | 194 | — |
| 09:48:xx | `123456.json` | `echo hhhh` | 196 | — |

> 观测到 `echo 123` 多次下发。经操作者确认，该现象系人工多次下发所致；
> 本次数据未观察到系统层面自动重发。

### 2.5 字段速查（下发）

| 偏移 | 长度 | 值 | 说明 |
|---|---|---|---|
| 0x00 | 4 | `BE`（190） | ★ `16+正文长度`（echo123 正文174→190；线上实际 194） |
| 0x04 | 4 | `0D`（13） | cmdType |
| 0x08 | 4 | 0 | 保留 |
| 0x0C | 4 | 0 | 保留 |
| 0x10 | 4 | 0 | body_len（下发观测恒为 0，接收端不依赖） |
| 0x14 | ... | JSON | UTF-16LE（多行，见 §2.1） |

> ★ **关键（抓包实证）**：`total_len` 字段 = `16 + 正文长度`（不是 20+），线上实际字节比字段多 4。

## 三、关键符号（静态分析）

### 3.1 教师端（`Teacher.exe` / `MainLogic.dll`）

| 字符串 / 符号 | 说明 |
|---|---|
| `RemoteCommand` | 命令消息 |
| `RemoteCommand.cache` | 命令缓存文件 |
| `RemoteCommands` | 命令列表 |
| `SetRemoteCommand` | 设置远程命令（导出函数，真身 `0x10019c10`） |
| `iCmd` | 命令 ID |
| `sRemoteIp` | 远程 IP |
| `CRemoteCommandDlg` | 命令对话框 |
| `C:\Windows\System32\cmd.exe` | 调用的程序 |

### 3.2 命令类型码

核心处理函数 `FUN_10075250`，命令类型码：

| 类型码 | 十六进制 | 说明 |
|---|---|---|
| 13 | `0x0D` | 远程命令（抓包实测的类型） |
| 39 | `0x27` | — |
| 40 | `0x28` | 读 JSON 键 `text`（命令文本）+ `second`（参数） |
| 41 | `0x29` | 实际执行点（`KillProc` 走此码） |

## 四、学生端执行链路（静态分析）

```
学生端 Student.exe / StudentLogic.dll
  └─ executor 机制分发（"bad executor" 为错误提示）
       ├─ SYS_RunCommand（systemoper.dll 导出）
       │    └─ ShellExecuteW("open", "cmd.exe", "/k <命令>")
       └─ OE_RunProcess / OE_RunProcessByUser（MmcImplBase.dll 导出）
            └─ CreateProcess（普通 / 指定用户身份）
```

### 4.1 SYS_RunCommand（`systemoper.dll` 导出）

反编译 `systemoper.dll FUN_10007580`：

```c
// 命令 = "/k " + 用户命令
local_228 = L"/k ";          // cmd.exe /k（执行后保持窗口）
ShellExecuteW(0, L"open", L"cmd.exe", L"/k命令", 0, param_2);
```

- 通过 `ShellExecuteW("open", "cmd.exe", "/k <命令>")` 执行；
- `param_2` 为显示方式（可隐藏窗口）。

### 4.2 OE_StopProcess / OE_StopProcessW（`MmcImplBase.dll` 导出）

```c
OE_Sprintf(local_108, "/c taskkill /F /IM %s");
ShellExecuteA(0, "open", "cmd.exe", "/c taskkill /F /IM <进程名>", 0, 0);
```

### 4.3 OE_RunProcess / OE_RunProcessByUser（`MmcImplBase.dll` 导出）

运行进程（普通 / 以指定用户身份）。

## 五、完整链路图

```
教师端 Teacher.exe
  └─ 选择"远程命令" → 构造 JSON {Para, Path, Tag}
       └─ 9003 通道（cmdType=0x0D）发送
            └─ 学生端 StudentLogic.dll 接收
                 └─ executor 机制分发
                      └─ SYS_RunCommand / OE_RunProcess
                           └─ ShellExecuteW("cmd.exe /k命令") 或 CreateProcess
                                └─ 回执 "1"
```

---

## 六、提示与注意点

- 命令执行依赖 `cmd.exe`（`/k` 参数），因此劫持 `cmd.exe`（映像劫持）可干扰远程命令执行。
- `StudentLogic.dll` 中存在 `bad executor` 提示，说明有"执行器"抽象，支持不同执行方式（命令 / 进程 / 直接 exe）。
- 相关可执行文件：`client_console.exe`、`transfer_console.exe`、`ConfBackupRestore.exe`、`BlackSlient.exe` 等由学生端按需启动。
