## 四、安全相关配置

```
/IpAddressFilter//        ← 空值 = 无来源 IP 过滤
/Limit/1/                 ← 管控使能
/channel/2/               ← 频道号（编码值 = 1<<2 = 4）
/multichannel/1/          ← 多频道支持开启
```

## 五、配置程序与配置文件（本地配置）

端口/频道等参数由安装目录下的配置程序写入本地 INI 风格文件。

| 项 | 值 |
|---|---|
| 配置程序 | `MultiMediaConfig.exe`（安装目录根目录；PE32 GUI） |
| 读写方式 | `GetPrivateProfileIntW` / `WritePrivateProfileStringW`（INI 风格） |
| 目标文件 | `skin\core.conf`（另有 `user.conf`、`general.conf`、`skin\res.config`） |
| 生效方式 | 重启对应端程序 |

配置界面（`skin\*.xml`）：

| 对话框 | 标题 |
|---|---|
| `MultiMediaConfigDlg1.xml` | 多媒体配置（教材/教育阶段、IP 协议、行为管控） |
| `MultiMediaConfigDlg2.xml` | 学生端环境配置（网络频道） |
| `MultiMediaConfigDlg3.xml` | 环境配置（服务器 IP / 课堂作业服务器 IP） |
| `MultiMediaConfigDlg4.xml` | 学生端连接配置（频道 + 教师机 IP） |
| `StuSetConfigWnd.xml` | 学生端"设置"窗口 |

`core.conf` 中与频道/连接相关的键（节选）：

| 键 | 默认值 | 说明 |
|---|---|---|
| `/channel/` | 2 | 网络频道（值 = `1 << 频道号`） |
| `/multichannel/` | 1 | 多频道支持 |
| `/ChannelSwith/` | 1 | 频道机制开关 |
| `/AssistIp/` | 0.0.0.0 | 教师/协助 IP |
| `/RemoteIp/` | 0.0.0.0 | 连接地址 |
| `/OnceConfigIp/` | 1 | 一次性配置 IP |
| `/RegisterServerIp/` | 0.0.0.0 | 通道服务器地址 |
| `/VdiChannelServerPort/` | 8002 | 通道服务器端口 |
| `/ConnectPort/` | 9003 | 主控制连接 |
| `/UdpMessageControllerPort/` | 8040 | 控制器端口 |

> ⚠ `core.conf` 中**不存在** `channel` 以外的教师 IP 键名 `TeacherIp`；`MultiMediaConfig.exe` 内部字符串含 `TeacherIp` 与 `RemoteIp`，实际落入 `core.conf` 的对应键以运行时文件为准。
