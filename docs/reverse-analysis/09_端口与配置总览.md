## 四、安全相关配置

```
/IpAddressFilter//        ← 空值 = 无来源 IP 过滤
/Limit/1/                 ← 管控使能
/channel/2/               ← 频道号（编码值 = 1<<2 = 4）
/multichannel/1/          ← 多频道支持开启
```
