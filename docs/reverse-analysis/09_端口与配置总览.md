# 09 端口与配置总览

 > 本文汇总 Os-Easy 教学系统的**全部通信端口**（教师端↔学生端 + 本地 IPC），含端口映射表、读取点、端口-阶段矩阵、环境噪声澄清。
 > 数据来源：① 配置文件 `core_*.conf`（6 份，端口值权威）；② Ghidra x86 反编译 8 模块（端口读取点 模块@行号）；③ 现场抓包（09-14/09-15/09-20 方向与频率）。
 > 首次分析：2026-09-15 · 本轮全量端口枚举 + 读取点坐实：2026-10-23

 > **本轮关键澄清**：抓包中出现的高频端口 `8091` **不是 Os-Easy 端口**（100% 来自外部公网 IP，环境噪声）；`8002/8003` 的抓包"命中"是 **TLS 记录头 `16/17 03 03` 误匹配**（实为 MSN/浏览器 telemetry，非 Os-Easy HTTP 注册）。详见 §二。

### 1.3 环境噪声澄清（本轮坐实，防误判）

| 端口 | 现象 | 结论 | 证据 |
|---|---|---|---|
| **8091** | 抓包高频（7696 次），`TCP 45.207.220.121:8091 ↔ 学生端:59xxx` | **非 Os-Easy 端口**。100% 流量源/目为外部公网 IP（本分析环境机），属环境噪声；反编译 `0x1f9b` 命中全为函数名 `FUN_1001f9b0` 误匹配 | 抓包 `50_big.log:11`；grep `0x1f9b` = `FUN_1001f9b0`(stul@31867) |
| **8002/8003** | 抓包"命中" | **非可靠 Os-Easy HTTP 注册流量**。命中为 TLS 记录头 `16 03 03`/`17 03 03` 误匹配，SNI 为 `browser.events.data.msn.cn` 等 telemetry | `50_big.log:1984/2445`（TLS 1.2/1.3 ClientHello） |
| 7771 组播 | `229.9.<ip3>.<ip4>` | 合法发现组播（教师自宣告） | [01](./01_教师发现机制与广播.md) |

> 反编译"端口常量误匹配"通病：十进制端口值不以字面常量出现，搜 `7777`/`0x1f9b`/`0x2332` 等命中的多为**函数名（`FUN_1005ae30` 类）或符号地址**，须结合配置键 + 上下文判断，不能仅凭数字命中断言端口。

## 四、安全相关配置

/IpAddressFilter//        ← 空值 = 无来源 IP 过滤
/Limit/1/                 ← 管控使能
/channel/2/               ← 频道号（编码值 = 1<<2 = 4）
/multichannel/1/          ← 多频道支持开启

## 五、配置程序与配置文件（本地配置）

端口/频道等参数由安装目录下的配置程序写入本地 INI 风格文件。

| 项 | 值 |
|---|---|
| 配置程序 | `MultiMediaConfig.exe`（安装目录根目录；PE32 GUI） |
| 读写方式 | `GetPrivateProfileIntW` / `WritePrivateProfileStringW`（INI 风格） |
| 目标文件 | `skin\core.conf`（另有 `user.conf`、`general.conf`、`skin\res.config`） |
| 生效方式 | 重启对应端程序 |

配置界面（`skin\*.xml`）：

| 对话框 | 标题 |
|---|---|
| `MultiMediaConfigDlg1.xml` | 多媒体配置（教材/教育阶段、IP 协议、行为管控） |
| `MultiMediaConfigDlg2.xml` | 学生端环境配置（网络频道） |
| `MultiMediaConfigDlg3.xml` | 环境配置（服务器 IP / 课堂作业服务器 IP） |
| `MultiMediaConfigDlg4.xml` | 学生端连接配置（频道 + 教师机 IP） |
| `StuSetConfigWnd.xml` | 学生端"设置"窗口 |

`core.conf` 中与频道/连接相关的键（节选）：

| 键 | 默认值 | 说明 |
|---|---|---|
| `/channel/` | 2 | 网络频道（值 = `1 << 频道号`） |
| `/multichannel/` | 1 | 多频道支持 |
| `/ChannelSwith/` | 1 | 频道机制开关 |
| `/AssistIp/` | 0.0.0.0 | 教师/协助 IP |
| `/RemoteIp/` | 0.0.0.0 | 连接地址 |
| `/OnceConfigIp/` | 1 | 一次性配置 IP |
| `/RegisterServerIp/` | 0.0.0.0 | 通道服务器地址 |
| `/VdiChannelServerPort/` | 8002 | 通道服务器端口 |
| `/ConnectPort/` | 9003 | 主控制连接 |
| `/UdpMessageControllerPort/` | 8040 | 控制器端口 |

> ⚠ `core.conf` 中**不存在** `channel` 以外的教师 IP 键名 `TeacherIp`；`MultiMediaConfig.exe` 内部字符串含 `TeacherIp` 与 `RemoteIp`，实际落入 `core.conf` 的对应键以运行时文件为准。
