# 17 黑屏肃静功能

## 一、功能定义

**「黑屏肃静」是系统中的一个独立功能**（UI 词条名即"黑屏肃静"）。

其行为：**学生屏幕整体变黑，仅显示教师端自定义的提示文字**。

| 项 | 值 |
|---|---|
| 功能名 | **黑屏肃静** |
| 解除功能 | **黑屏解锁** |
| 通道 | `tcp/9003`（`ConnectPort`） |
| cmdType | `12`（`0x0C`） |
| 方向 | 教师端 → 学生端 |
| 正文编码 | UTF-16LE |

> 该功能是一个整体：**黑屏（屏幕背景变黑）** 与 **肃静（显示提示文字）** 由**同一条指令**触发，共同构成"黑屏肃静"。

## 三、报文格式（现场抓包实证）

### 3.1 开启黑屏肃静

`123.json`，09:34:50.069，总长 44 字节：

```
HDR  : 2C 00 00 00 | 0C 00 00 00 | 00 00 00 00 | 00 00 00 00 | 18 00 00 00
BODY : 2F 00 31 00 2F 00 请 大 家 保 持 安 静 ！ 2F 00
       (UTF-16LE)  /  1  /  请 大 家 保 持 安 静 ！  /
```

正文解码：`/1/请大家保持安静！/`

> 其中 `请大家保持安静！` 即**教师在教师端自定义的提示文字**。

### 3.2 解除黑屏肃静

总长 28 字节：

```
HDR  : 1C 00 00 00 | 0C 00 00 00 | 00 00 00 00 | 00 00 00 00 | 08 00 00 00
BODY : 2F 00 30 00 2F 00 2F 00
```

正文解码：`/0//`

### 3.3 正文格式

```
/<开关>/<自定义文字>/
```

| 字段 | 取值 | 含义 |
|---|---|---|
| `开关` | `1` | 开启黑屏肃静 |
| `开关` | `0` | 解除（黑屏解锁） |
| `自定义文字` | 教师输入的文本 | 黑屏时屏幕上显示的内容；解除时为空 |

### 3.4 字段速查

| 偏移 | 长度 | 值（开启） | 值（解除） |
|---|---|---|---|
| 0x00 | 4 | `2C`（44） | `1C`（28） |
| 0x04 | 4 | `0C`（12） | `0C`（12） |
| 0x08 | 4 | 0 | 0 |
| 0x0C | 4 | 0 | 0 |
| 0x10 | 4 | `18`（24） | `08`（8） |
| 0x14 | 24 / 8 | UTF-16LE 正文 | UTF-16LE 正文 |

## 五、功能链路

```
教师端
  [菜单 menu_BlackSilence "黑屏肃静"]
    └─ CLockStuDlg（输入自定义文字 / 可选设置时间）
         └─ 构造 "/1/<自定义文字>/"
              └─ 9003 通道（cmdType=0x0C）发送
═══════════════════════════════════════════════════
学生端
  收到 cmdType=0x0C
    └─ BlackSlient.exe 启动
         ├─ 全屏黑色窗口（黑屏）
         └─ 显示自定义文字（肃静提示）

解除：
  [菜单 menu_BlackUnlock "黑屏解锁"]
    └─ 发送 "/0//"（cmdType=0x0C） → 学生端关闭黑屏窗口
```

## 六、现场验证

操作者在机房对目标机执行"黑屏肃静"，现象与上述机制一致：

| 观测 | 结论 |
|---|---|
| 学生屏幕整体变黑 | 黑屏（`BlackSlient.exe` 全屏窗口） |
| 屏幕上显示教师自定义文字 | 肃静（`/<开关>/<文字>/` 中的文字部分） |

## 七、与 8040 端口的关系

`UdpMessageControllerPort`（8040）被 `StudentScreenHelper.exe` 引用，但**本次黑屏肃静实测走 9003**（cmdType=0x0C）。8040 的实际用途见 [21 号报告](./21_8040端口缺席调查.md)。
