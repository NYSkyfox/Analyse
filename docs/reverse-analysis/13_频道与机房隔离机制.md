# 13 频道（Channel）与机房隔离机制

> 本报告回答：**多机房网络互通时（如 A=192.168.1.x、B=192.168.2.x），教师端如何避免学生串到隔壁机房？**
> 结论：隔离靠 **频道（channel）+ 通道服务器注册/匹配**（应用层），**与 IP 网段无关**。
> 方法：反汇编（`MainLogic.dll` / `StudentLogic.dll`）+ 配置文件（`skin/core.conf`）+ UI（`skin/*.xml`）。

---

## 〇、结论速览

| 问题 | 结论 |
|---|---|
| 隔离靠什么？ | **频道号（channel）**，通过**通道服务器**注册/匹配 |
| 是网络层（VLAN/网段）隔离吗？ | ❌ 不是。广播可能跨机房（用户实测），隔离在应用层 |
| 是不是服务器配置的？ | ✅ 是。由噢易**通道服务器**（`VdiChannelServerPort=8002`）维护"频道↔教师IP"映射 |
| 教师怎么知道自己属于哪个机房？ | **登录时手动选择频道**（`LoginWnd.cpp_PleaseSelectChannel`） |
| 学生怎么找到本机房教师？ | 学生按自己频道向服务器 `channel_match` 查询教师 IP |

## 一、证据链

### 1.1 配置文件 `skin/core.conf`（权威）

```
/VdiChannelServerPort/8002/     ← ★ 通道服务器端口
/RegisterServerIp/0.0.0.0/      ← 通道服务器地址
/RegisterServerPort/8003/       ← 注册服务端口
/ChannelSwith/1/                ← 频道机制开关（1=启用）
/ChannleScanPort/7777/          ← 频道扫描端口
```

### 1.2 教师端：`channel_register`（MainLogic.dll）

反汇编定位到 URL 构造（VA `0x100685d4` 附近）：

```asm
100685c5  MOV EAX,[EDX+0x5e8]        ; 取参数（频道相关）
100685cb  CMP EAX,[EBP+0x8]
100685ce  JNE 0x1006877a
1006861b  PUSH 0x10152fb8            ; "VdiChannelServerPort"
10068642  PUSH 0x10152fd0            ; "http://%s:%d/channel_register"
100686a7  PUSH 0x10152ff0            ; "ip=%s&channel=%d"
100686b2  CALL 0x10008790            ; 格式化
```

字符串表（`MainLogic.dll`）：

| VA | 内容 |
|---|---|
| `0x10152fa4` | `RegisterServerIp` |
| `0x10152fb8` | `VdiChannelServerPort` |
| `0x10152fd0` | `http://%s:%d/channel_register` |
| `0x10152ff0` | `ip=%s&channel=%d` |

→ 教师端请求：`http://<RegisterServerIp>:<VdiChannelServerPort>/channel_register?ip=<教师IP>&channel=<频道号>`

### 1.3 学生端：`channel_match`（StudentLogic.dll）

反汇编定位（VA `0x1001c687` 附近）：

```asm
1001c662  MOV EAX,[EBP-0x244]
1001c668  MOVSX ECX,WORD PTR [EAX+0x8]   ; 取频道值
1001c66c  ADD ECX,0x1
1001c67b  PUSH EDX                        ; 格式化 "channel=%d"
1001c687  PUSH 0x10234b4c                 ; "http://%s:%d/channel_match"
1001c692  CALL 0x10013040                 ; 构造字符串
1001c6cb  PUSH 0x10234b7c                 ; 取端口
1001c6db  CALL 0x1000a920
```

字符串表（`StudentLogic.dll`）：

| VA | 内容 |
|---|---|
| `0x10234b4c` | `http://%s:%d/channel_match` |
| `0x10234b68` | `channel=%d` |
| `0x10234b7c` | （端口格式串） |
| `0x10234bf8` | `ChannelRegisterServer` |

→ 学生端请求：`http://<服务器>:<port>/channel_match?channel=<频道号>`，服务器返回该频道对应的教师 IP。

### 1.4 UI 证据

| 文件 | 内容 |
|---|---|
| `skin/ChannelMenuWnd.xml` | 频道列表：**「1频道」「2频道」…「18频道」+**（可勾选，`userdata=1..N`） |
| `skin/ChannelListElement.xml` | 频道列表元素（`EditChannelList` 输入框 + 删除按钮） |
| `Teacher.exe` 字符串 | `LoginWnd.cpp_PleaseSelectChannel`（**登录时选频道**）、`channeltoclass.cache`、`multichannel` |

## 二、隔离流程（完整时序）

```
【教师端启动】
   登录 → 弹出"选择频道"对话框（PleaseSelectChannel）
        │   老师选择【本机房频道 = N】
        ▼
   向通道服务器注册：
   http://<RegisterServerIp>:8002/channel_register?ip=<教师IP>&channel=N
        │
        ▼
  【噢易通道服务器 (VdiChannelServerPort=8002)】
        记录映射：  频道 N  →  教师IP
        ▲
        │
【学生端启动】
   读取自身频道 N（本地配置/服务器下发）
        │
        ▼
   查询通道服务器：
   http://<服务器>:8002/channel_match?channel=N
        │
        ▼
   服务器返回该频道的教师 IP → 学生端连接该教师
```

## 三、为什么"老师的教师端不会串"，而"你开教师端会串"

| 现象 | 原因 |
|---|---|
| 老师 A（机房A）与老师 B（机房B）互不干扰 | 两人在登录时**选择了不同频道**（如 A=1频道，B=2频道），服务器按频道隔离映射 |
| 你在学生机上开教师端 → 连到隔壁 | 你的临时教师端使用**默认/未配置频道**，恰好与该学生机（或隔壁）频道一致 |
| 学生机开机自动归属本机房 | 学生端本地（或服务器下发）已配置好"我属于哪个频道" |

> 💡 **本质**：隔离是**应用层（频道号 + 服务器协调）**实现的，**不依赖 IP 网段**。所以哪怕 A、B 机房网络完全互通，只要频道不同就不会串。

## 四、channel 取值：编号 vs 位掩码（待确认）

抓包观察到的 channel 值与 UI 编号不完全对应：

| 教师 IP | 抓包 channel | UI 可能对应 |
|---|---|---|
| 192.168.0.200 | `2` | 1频道? |
| 192.168.1.200 | `4` | 2频道? |
| 192.168.2.200 | `8` | 3频道? |
| 192.168.3.200 | `16` | 4频道? |
| 192.168.5.18 | `4` | 2频道? |

`2,4,8,16` 呈 **2 的幂**，符合"**位掩码** `2^(编号-1)`"的推测（早期报告已有此假设），但也可能 channel 直接就是编号。

> ⚠️ **待验证**：反汇编 `Teacher.exe` 的 `PleaseSelectChannel` 逻辑，确认选中的编号是否做了移位（`1 << (n-1)`）。

## 六、对"注入工具"的影响

### 6.1 关键：频道只管"发现"，不管"管控"

```
通道服务器(8002) ── 负责"谁是谁的教师"（发现/匹配）
       │
教师 ──8040 直连──→ 学生IP        （管控，不经通道服务器）
教师 ──7778 组播──→ 学生          （屏幕广播）
教师 ──7777 广播──→ 学生          （身份公告，带 channel 字段）
```

| 工具能力 | 是否需要知道频道 |
|---|---|
| **向目标 8040 注入管控/解除** | ❌ **不需要**（直连目标 IP 即可，无 IP 校验） |
| **冒充教师让某机房学生认你** | ✅ **需要**用该机房的频道注册 |
| **判断目标机属于哪个机房** | 可用 7777 广播里的 `channel` 字段 |
| **跨机房注入**（A 机房 → B 机房学生） | ✅ 网络互通即可，**管控不受频道限制** ⚠️ |

### 6.2 安全含义

- **频道是"发现层"的隔离，不是"控制层"的隔离**。
- 只要知道目标学生机 IP，即可直接注入 8040，**无需经过通道服务器、无需正确频道**。
