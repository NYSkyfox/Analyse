# GUI 使用指南

## 启动 GUI

### 方法一：快速入口（需图形环境）

```bash
python main.py
```

### 方法二：强制 GUI 模式

```bash
python main.py --gui
```

### 方法三：运行示例文件

```bash
python examples/gui_example.py
```

## 界面介绍

### 主窗口布局

```
┌─────────────────────────────────────┐
│ 文件  编辑  帮助                     │  <- 菜单栏
├─────────────────────────────────────┤
│ ┌─ 输入 ───────────────────────┐   │
│ │ 数据: [__________________]    │   │  <- 输入区域
│ └───────────────────────────────┘   │
│                                     │
│    [处理]  [清空]                   │  <- 操作按钮
│                                     │
│ ┌─ 输出 ───────────────────────┐   │
│ │                               │   │
│ │  (输出结果显示在这里)          │   │  <- 输出区域
│ │                               │   │
│ └───────────────────────────────┘   │
│ 状态: 就绪                          │  <- 状态栏
└─────────────────────────────────────┘
```

## 功能说明

### 菜单栏

**文件菜单**
- 新建 - 清空所有输入和输出
- 打开 - 从文件加载输入数据
- 退出 - 关闭应用

**编辑菜单**
- 清空 - 清空输出区域

**帮助菜单**
- 关于 - 显示应用信息

### 操作流程

1. 在"数据"输入框中输入要处理的数据
2. 点击"处理"按钮
3. 在输出区域查看结果
4. 可继续输入并处理更多数据
5. 点击"清空"按钮清除输出历史

## 主题

GUI 使用 ttk 组件并尝试应用 Vista 主题，在不同平台上表现如下：
- **Windows**: vista 主题（现代外观）
- **macOS**: aqua 主题（原生外观）
- **Linux**: clam 主题（清爽外观）

## 自定义

界面代码位于 `src/gui/window.py`。

### 修改窗口大小

```python
self.root.geometry("1024x768")  # 修改为你想要的尺寸
```

### 修改主题

```python
self.style.theme_use("alt")  # 使用其他主题
```

可用主题: default, classic, alt, clam, vista (Windows)

## 常见问题

### GUI 无法启动？

确保系统已安装 tkinter：
```bash
# Ubuntu/Debian
sudo apt-get install python3-tk

# macOS (通常已内置)
# Windows (通常已内置)
```

### 如何在后台运行？

GUI 需要前台窗口，如需后台处理请使用 CLI 模式。

### 可以同时打开多个窗口吗？

可以，只需多次运行程序即可。
