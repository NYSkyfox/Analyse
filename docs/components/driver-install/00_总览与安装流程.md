## 一、安装入口（.bat）

```bat
:: student_install_control.bat
cd /d %~dp0
DriverInstall.exe /S /DIR=%~dp0 /OPT=install /d1=FbdATS /d2=easyusbflt /d3=ProcFireWall /d4=OeNetLimit
shutdown -r -t 0

:: teacher_install_control.bat
ModifyLimitConfig.exe
shutdown -r -t 0

:: uninstall_kbfilter.bat
DriverInstall.exe /S /DIR=%~dp0 /OPT=uninst /d1=KbFilter
shutdown -r -t 0

:: uninstall_server.bat
sc stop MultiTeachingServerLoader
sc delete MultiTeachingServerLoader
```

- `DriverInstall.exe` 是 **NSIS 安装器**（`Nullsoft Install System v2.46`，`requireAdministrator`），按 `/OPT=install|uninst` 与 `/d1..d4` 选择要装/卸的驱动。
- `/DIR=%~dp0` 把**当前目录**作为安装目录（`$INSTDIR`），也是驱动文件来源。
- 装完**强制重启**（`shutdown -r -t 0`）。

## 三、统一安装模型

所有 `*install*.exe` / `LoadDriver.exe` / `OeNetLimitSetup.exe` 都是同一套模式的变体：

```
1. GetModuleFileName → 截去自身文件名，得到"安装目录"
2. CopyFile("<安装目录>\<drv>.sys", "C:\Windows\System32\drivers\<drv>.sys")
3. OpenSCManager → CreateService(名字, 名字, SERVICE_ALL_ACCESS,
        dwServiceType = SERVICE_KERNEL_DRIVER, dwStartType = 1/2/3, lpBinaryPathName = drivers 里的 .sys)
4. StartService / ControlService（失败时打印 ERROR_FILE_NOT_FOUND / ALREADY_RUNNING / PENDING）
5. 卸载：OpenService → ControlService(STOP) → DeleteService → 删文件
```

安装后服务 `ImagePath` 统一指向 `C:\Windows\System32\drivers\<drv>.sys`；各安装器内部对 `StartService` 的常见返回码（`ERROR_FILE_NOT_FOUND` / `ERROR_SERVICE_ALREADY_RUNNING` / `ERROR_IO_PENDING`）均有分支处理。

## 四、卸载

- 单个驱动：`DriverInstall.exe /OPT=uninst /d1=<名>` 或对应 `*install*.exe /uninstall`。
- `KbFilter`：`uninstall_kbfilter.bat`。
- 服务层操作：`sc stop` / `sc delete`。
- `OeNetLimitSetup.exe` 卸载会 `SHDeleteKey` 掉 `...\services\OeNetLimit` 与 `...\Oenetlimittmp`。

## 六、与 MMPC 体系的关系

```
MMPC.exe ──npd-auto──▶ DeviceControl_x64.exe ──▶ NetLimitInterface.dll ──▶ OeNetLimit.sys（网络限制）
                       （本安装包负责把这些驱动/组件部署到系统）
MMPC ──npd/守护──▶ 保护 DeviceControl/Student 进程（AntiHelper→mtpcpt.sys）
```

`student_install_control.bat` 是 **学生端部署** 入口：一次性装 4 个底层驱动
（`FbdATS` 设备资产、`easyusbflt` USB、`ProcFireWall` 进程、`OeNetLimit` 网络），随后重启生效。
