# 02 行为管控

> ⚠️ **修正说明**（结合 core.conf 与你仓库仲裁报告）：本报告早期版本存在两处错误，已在 [09_管控指令协议定稿](./09_管控指令协议定稿.md) 修正：
> 1. 管控端口 8040 = `UdpMessageControllerPort`（**不是** ConnectPort，ConnectPort=9003）；
> 2. 管控指令接收器是 **StudentLogic.dll + LissHelper.exe**（MMPC 是守护进程/进程保护，非管控接收器）。

## 一、管控指令通道（修正后）

```
教师端 Teacher.exe
  └─ CtrlCode JSON 构造 → 16B头[cmdType][flag1][flag2][len] + "/*//" + JSON
       └─ 遍历在线学生 → 单播 UDP → 学生机 8040 (UdpMessageControllerPort)
═══════════════════════════════════════
学生端 StudentLogic.dll（8040 接收）
  └─ 解析 cmdType → 翻译成 JSON {"type":"support/stop-device-control",...}
       └─ UDP → 127.0.0.1:8045 → DeviceControl.exe
            └─ NetLimitInterface.dll → OeNetlimit.dll → 驱动执行
（另：LissHelper.exe 也是管控接收器，UDP+JsonCpp 按 type 分发）
```

## 二、管控指令 JSON 格式

反编译 `MMPC.exe FUN_0043ab20`，完整还原 multimedia 指令模板：

```json
{"method":"multimedia","args":{"teacher_ip":"...","student_ip":"..."},"msg_id":"", "extras":{}}
```

## 三、MMPC 守护进程的完整指令表（19 种 `type`）

反编译 `MMPC.exe FUN_00438b70`，指令通过 JSON `type` 字段分发：

| type | 作用 |
|---|---|
| `daemon` | 守护 |
| `quit-daemon` | 退出守护 |
| `npd-auto` | 自动 NPD（启动保护设备控制） |
| `multi-config` | 多客户端配置 |
| `vdi` | VDI 相关 |
| `quit` | 退出 |
| `uninstall` | 卸载 |
| `start-teacher` | 启动教师端 |
| `killallproc` | 杀所有进程 |
| `set-teaAndStu-ip` | 记录教师/学生 IP（字段 `teaIp`/`stuIp`） |
| `start-multiclient` | 启动 `MultiClient.exe 教师IP 学生IP` |
| `regedit-broadcast` | 读 `broadcast` 字段 → 触发键盘锁 |
| `desktop-type` | 桌面类型 |
| `terminal-mac` | 终端 MAC |
| `idv-terminal-mac` | IDV 终端 MAC |
| `set-time` | 设置时间 |
| `kill-deviceControl` | 杀 DeviceControl 进程 |
| `kill-student` | 杀 Student.exe |
| `start-lissNet` | 启动 `LISSNetInfoSniffer.exe`（带 ip/mac/filepath） |

关键日志对应（log.txt）：`receive type:regedit-broadcast` → `broadcast state:0` → `already exist`（键盘锁）。

## 四、驱动级限制原理

| 驱动 | 机制 | 能力 |
|---|---|---|
| `easyusbflt.sys` | 设备栈过滤 + USB 白名单 | USB 限制 |
| `KbFilter.sys` | Hook IRP_MJ_CREATE + IOCTL | 键盘锁（多级） |
| `OeNetLimit.sys` | NDIS LWF + WFP + 速度控制 + DNS白名单 | 网络限制/断网/限速 |
| `ProcFireWall.sys` | PsSetCreateProcessNotifyRoutine | 程序限制 |
| `FbdATS.sys` | SFilter 文件过滤 | 文件监控 |

### KbFilter.sys 键盘锁等级（IOCTL）
```
IOCTL_KB_INIT / IOCTL_KB_STOP / IOCTL_KB_DISABLE_SPEC
KEYBOARD_ALL_DISALE                              // 全锁
KEYBOARD_ALL_DISALE_EXCEPT_CTRLENTER             // 除 Ctrl+Enter
KEYBOARD_ALL_DISALE_EXCEPT_PASSWORD              // 除密码
KEYBOARD_ALL_DISALE_EXCEPT_PASSWORD_AND_CHINESE  // 除密码+中文
KEYBOARD_ALL_DISALE_EXCEPT_PASSWORD_AND_CHINESE_AND_ALT
KEYBOARD_DISABLE_TASK_MGR                        // 禁任务管理器
KEYBOARD_ALL_RELEASE                             // 释放
```

### OeNetLimit.sys 网络限制
```
IOCTL_SET_SpeedControl disableInternet:%d disableNet:%d isDownLimit:%d
WfpRegisterCallouts / FwpmFilterAdd   // WFP 过滤
AddDnsWhiteListIp                      // DNS 白名单
ProcessCreateMon                       // 进程创建监控
```

## 五、⚠️ 是否校验教师 IP（安全关键）

从 `FUN_00438b70`（MMPC 指令分发）反编译看：**解析 JSON 后直接按 `type` 字段分发执行，未对来源 IP 做校验**。教师 IP（`teaIp`）仅用于后续启动参数，非鉴权依据。

→ **理论上，伪造指令格式 + 向学生端管控端口发送，学生端会照常执行**（除非上层 Student.exe 8040 接收逻辑另有校验，或指令经 SSL 加密，见 07 报告）。
