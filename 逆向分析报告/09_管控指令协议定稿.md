## 二、管控指令协议（最终定稿）

### 2.1 线格式：16 字节头 + 载荷

```
[cmdType:u32][flag1:u32][flag2:u32][payloadLen:u32]  +  载荷
```

> ⚠️ **重要修正**：早期关于 `/*//` 前缀的说法，已由 [10_行为管控报文核查定稿](./10_行为管控报文核查定稿.md) 用反汇编纠正——`/*//` 是**死代码，不是载荷前缀**。请以 10 报告为准。

- 网络限制 `cmdType = 500`
- 其他 cmdType：11 / 13 / 28 / 79 / 111
- 载荷：**纯 JSON，无 `/*//` 前缀**（见 10 报告）

### 2.2 载荷：CtrlCode JSON

教师端 `Teacher.exe FUN_005648c0` 读 `NPDControl.json` 按位构造，`FUN_0059ca10` 组装 JSON：

```json
{
  "CtrlCode": 19,
  "apps":  [{"app":"notepad","exec":"C:\\...\\notepad.exe","type":1}],
  "cites": [{"cite":"www.baidu.com","type":1}],
  "keys":  [{"keyName":"surf"}],
  "sendState": 1,
  "tipInfo": "上课请勿浏览与学习无关的网站！",
  "serverIp": "192.168.1.100"
}
```

### 2.3 CtrlCode 位标志（核心）

| 位 | 值 | 管控项 | 字段 |
|---|---|---|---|
| bit0 | 0x01 | **网络禁用** | `DisabledNet` |
| bit1 | 0x02 | 键盘过滤 | `EnableNetKeyFilter` |
| bit4 | 0x10 | 应用禁用 | `DisabledApp` |
| bit8 | 0x100 | USB 禁用(变体1) | `DisabledUsb` |
| bit12 | 0x1000 | USB 禁用(变体2) | `DisabledUsb` |
| bit16 | 0x10000 | USB 禁用(变体3) | `DisabledUsb` |

## 三、完整管控链路（定稿）

```
教师端 Teacher.exe (FUN_005648c0)
  └─ 读 NPDControl.json → CtrlCode 位标志
       └─ FUN_0059ca10 构造 JSON → MainLogic.dll UnLoad → FUN_10067f50 存入 this+0x548
            └─ FUN_10064770：16B头[500][0][0][len] + JSON（无前缀）
                 └─ FUN_1009e070 遍历在线学生列表 → 单播 UDP → 学生机:8040
═══════════════════════════════════════
学生端 StudentLogic.dll（8040 接收）
  └─ 解析 cmdType(500) → 翻译成 JSON：
       {"type":"support-use-device-control"/"stop-device-control",
        "network":x, "networktraffic":x, "device":x, "process":x}
       └─ UDP → 127.0.0.1:8045 → DeviceControl.exe
            └─ 加载 NetLimitInterface.dll → OeNetlimit.dll
                 └─ DisableInternet/DisableNet/SetWhiteIP/SetBlackUrl
                      └─ DeviceIoControl(\\.\OeNetLimit) → OeNetLimit.sys(WFP) → 断网
```

## 四、网络限制指令的最终答案（回应你之前的问题）

**"启用/关闭网络限制"没有独立的 JSON，它是两层协议：**

1. **教师端→学生端**（网络）：`[500][0][0][len]` + `{"CtrlCode":1, "cites":[...], "serverIp":"..."}`（**无** `/*//` 前缀）
   - `CtrlCode & 0x01` = 禁用网络
2. **学生端内部**（本地 IPC，127.0.0.1:8045）：`{"type":"support-use-device-control", "network":1, ...}`
3. **最终执行**：`OeNetlimit.dll::DisableInternet(server_ip)` → 驱动断网

## 五、远程命令协议（定稿）

- 功能 = `CRemoteCommandDlg` + `RemoteCommand` 消息 + `SetRemoteCommand` 导出（**真身 0x10019c10**，导出表错位陷阱）
- 核心 `FUN_10075250`，命令类型码：0x0d(13)/0x27(39)/0x28(40)/0x29(41)
- type=0x28/0x29 时读 JSON 键 `text`（命令文本）+ `second`（参数）
- 载荷 = 4 字节命令类型码 + UTF-16 文本，消息类型 `L"RemoteCommand"`
- 实际执行点：`KillProc` 走 type=4 → 命令码 0x29

## 六、安全结论（无 IP 校验实锤）

`core.conf` 中 **`/IpAddressFilter//`（空值）= 无 IP 过滤**。结合：
- 管控走 UDP 明文（16B 头 + JSON）
- 学生端 LissHelper/StudentLogic 解析后直接执行，不校验源 IP

→ **任意局域网机器构造 `[500][0][0][len] + CtrlCode JSON` 发 UDP→学生机:8040，即可远程管控**（断网/禁应用/禁USB/锁键盘）。
