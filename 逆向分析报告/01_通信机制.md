# 01 学生端与教师端之间的通信

## 一、发现机制总览

系统采用**双通道发现机制**，教师端同时做两件事（由同一定时器驱动，周期 3 秒）：

```
教师端 ──① UDP 广播(7777)──> 局域网内所有学生端
教师端 ──② HTTP 注册──> 中心注册服务器(channel_register)
```

## 二、① UDP 广播（你抓包的那条）

### 触发
`MainLogic.dll` 中 `SetTimer(..., 0x5e8, 3000ms)` 定时器每 3 秒触发，调用 `FUN_1005ae30` 构造广播 JSON，随后发送。

### 广播内容（反编译 `FUN_1005ae30`）
```json
{"teacher_ip":"192.168.0.200","checksum":210107,"channel":2,"msg_id":"teacherip"}
```

构造顺序（代码）：
```c
add("teacher_ip", 本机IP)   // local+0x40
add("checksum",  FUN_1004c380()) // 6位奇偶校验和，见 07 报告
add("channel",   频道号)     // local+0x3c
add("msg_id",    "teacherip")
```

### 端口
- 广播端口 = `ChannleScanPort`（频道扫描端口），你抓包确认 = **7777**
- 端口值**并非硬编码字面量**，通过配置系统 `FUN_10002a50()/FUN_10020aa0()` 从配置 map 动态读取。

## 三、② HTTP 频道注册

同一定时器里，教师端向中心服务器 POST：

```
http://{RegisterServerIp}:{VdiChannelServerPort}/channel_register?ip={教师IP}&channel={频道}
```

- `RegisterServerIp` — 注册服务器 IP（配置项）
- `VdiChannelServerPort` — VDI 频道服务器端口（配置项）

## 四、学生端如何找到教师端

1. 学生端监听 `ChannleScanPort`(7777) UDP 广播，收到后解析 `teacher_ip` + `channel`；
2. `StudentLogic.dll` 中 `get teacherip : %s`、`IpProto:%d,teacherip:%s` 记录教师 IP；
3. 也可通过 HTTP `http://IP:port/channel_match` 主动匹配频道；
4. 频道→班级映射缓存于 `channeltoclass.cache`（`ChannelToClass::Load/Save`）。

## 五、关键字段含义

| 字段 | 含义 |
|---|---|
| `channel` | 频道号（数字，如 2） |
| `teacher_ip` | 教师机 IP |
| `checksum` | 6 位奇偶校验和（算法见 07 报告） |
| `msg_id` | 消息类型标识（此处固定 `teacherip`） |

## 六、教师端/学生端 IP 的记录

- 教师端广播的是**自己的 IP**（`teacher_ip`）；
- 学生端收到 `set-teaAndStu-ip` 指令后，在 MMPC 内存结构记录 `teaIp`/`stuIp`（日志 `teaIp:192.168.1.200,stuIp:192.168.1.64`）；
- 教师 IP 后续用于启动 `MultiClient.exe 教师IP 学生IP` 等操作的参数，**并非用于鉴权**（见 02/07 报告）。
