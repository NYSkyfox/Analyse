# 07 建议点深挖（checksum / 加密 / IP校验）

## 一、checksum 算法（已完全逆向）

反编译 `MainLogic.dll FUN_1004c380`（teacherip 广播中 checksum 字段的生成函数）：

```c
*param_1 = 0;
for (local_c = 0; local_c < 6; local_c++) {
    *param_1 = *param_1 * 10;            // 十进制左移一位
    uVar1 = rand() & 0x80000003;         // rand() 取低2位+符号位
    if (uVar1 < 0) uVar1 = (uVar1-1|0xfffffffc)+1;  // 归约到 0~3
    uVar2 = local_c & 1;                 // 判断奇偶位
    if (uVar2 == 1)
        *param_1 = *param_1 + 1 + uVar1*2;   // 奇数位：1,3,5,7
    else
        *param_1 = *param_1 + uVar1*2;       // 偶数位：0,2,4,6
}
```

### 算法总结

- 生成一个 **6 位十进制数**；
- **奇数位是奇数（1/3/5/7）**，**偶数位是偶数（0/2/4/6）**；
- 基于 `rand()` 生成，规律明显，**无安全性**（可预测、可伪造）。

### 验证

你抓包的 `checksum:210107`：
- 位序（从左到右）1-6：2、1、0、1、0、7
- 偶数位（1/3/5）：2、0、0 → 都是偶数 ✓
- 奇数位（2/4/6）：1、1、7 → 都是奇数 ✓

完全符合规律。

## 二、加密（通信是否加密）

### 1. LISS SDK 使用 SSL/TLS

多个文件出现：
```
SSLKEYLOGFILE
C:\ProgramData\LISSClient\sslkey.log
[SetLissSslKey] failed
```

LISS SDK（行为管控核心）使用 SSL/TLS，并支持 SSL 密钥日志导出（`SSLKEYLOGFILE` 环境变量 + sslkey.log）。

### 2. Teacher.exe / Student.exe 的加密连接

```
Teacher.exe: EncryptDlg, Encrypt, AddTeacherEncryptConnect, BCryptOpenAlgorithmProvider
Student.exe: AddStudentEncryptConnect, SHA-1
```

- 教师端和学生端有 `AddTeacherEncryptConnect` / `AddStudentEncryptConnect` 加密连接功能；
- 使用 Windows BCrypt + CryptoPP（`StreamTransformationFilter`、PKCS 填充是 Crypto++ 特征）。

### 3. 结论

- 通信**存在加密层**（SSL/TLS + BCrypt + CryptoPP）；
- 但早期抓包（7777 广播）是**明文 JSON**（teacherip 广播未加密）；
- 管控指令是否加密取决于 LISS SDK 的实际配置（有 sslkey.log 说明可启用 SSL）。

## 三、IP 校验（学生端是否校验教师 IP）

### 分析结论

1. **MMPC 守护进程的指令分发（`FUN_00438b70`）不校验来源 IP**：
   - 解析 JSON 后直接按 `type` 字段分发执行；
   - 教师 IP（`teaIp`）仅通过 `set-teaAndStu-ip` 指令动态记录，用于后续启动参数，非鉴权依据。

2. **`MmcImplBase.dll` 提供 IP/MAC 校验函数**（OE_CheckIPv4Ip、OE_CheckMacAddr 等），但这是**网络参数合法性校验**（IP 格式是否正确），不是指令来源鉴权。

3. **安全风险**：如果指令通道未加密，攻击者构造合法 JSON 指令，即可绕过教师身份直接管控学生端。

### 待进一步确认

- 管控指令的实际接收端（Student.exe 8040 端口）是否在**更上层**做了来源 IP 过滤；
- 这需要动态抓包 + 伪造指令实测验证（静态分析未见明显 IP 鉴权逻辑）。

## 四、综合建议

| 方向 | 建议 |
|---|---|
| checksum | 已破解，可任意伪造 |
| 加密 | 依赖 LISS SDK SSL 配置，teacherip 广播为明文 |
| IP 校验 | 静态分析未见鉴权，建议动态实测确认 |
